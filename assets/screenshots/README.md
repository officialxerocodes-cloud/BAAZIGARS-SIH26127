# Project Screenshots

Live captures from the running TRINETRA system (Delhi CP–South Ex simulation, 60 virtual cameras). Displayed in the main `README.md` gallery.

## Shots in this folder

- `01-live-dashboard.png` — city breathing, alert ticker, honest LIVE badges
- `02-trajectory-live-trace.png` — one plate traced across the ANPR grid
- `03-area-sweep-ranking.png` — every vehicle in scope, ranked, one click retraces any of them
- `04-detection-evidence.png` — per-hop timestamps, confidence bars, sweep-scope insight
- `05-blacklist-admin.png` — blacklist admin + alerts inbox
- `06-analytics-page.png` — OD flows, congestion, camera health
- `07-anpr-ocr-detection.png` — vehicle detection and plate OCR on real footage

## Naming convention

`NN-short-kebab-case-description.png`, ordered as they appear in the README gallery:

- `01-home.png`
- `02-dashboard.png`
- `03-feature.png`
- `04-result.png`

Do not upload screenshots containing passwords, API keys, tokens, personal credentials, or other sensitive information.

## Adding screenshots to README

Reference them with a relative path, for example:

```md
![Live dashboard](assets/screenshots/01-live-dashboard.png)
```
